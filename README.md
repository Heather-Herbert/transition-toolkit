# Transition toolkit — issues

This is the public issue tracker for **Transition toolkit**, a private, offline Android app for trans people in the UK.

The app's source code is not here. This repository holds issues only.

## Before you post

GitHub issues are **public**, and they show your GitHub username.

- Do not post your medication, doses, blood results or any health details.
- Do not post anything that could identify you, if being trans is not public for you.
- Screenshots: check them first. Blank out anything personal.

If you would rather not post publicly, use a throwaway GitHub account.

## What to post

- **Bug report:** something does not work, or works wrongly.
- **Feature idea:** something you would like the app to do.
- **Content correction:** a wrong fact, broken link or out-of-date guidance.
- **Accessibility:** anything hard to use with a screen reader, large text, or when tired or unwell.

## Security

Please do not report security problems in a public issue. Use [private vulnerability reporting](../../security/advisories/new) instead.
